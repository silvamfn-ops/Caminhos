# Caminhos do Sul — Aplicação Web de Moto-Turismo & Guia Cultural (v2.0)

Aplicação PWA (Progressive Web App) com **Motor de Importação Inteligente (`.pptx` + `.kmz`/`.kml`)**, planeador para computador e interface mobile otimizada para iPhone e Android.

## Novidades da Versão 2.0 (Importação & Fusão Geográfica)
* **Leitura Estruturada de `.pptx`:** Deteta automaticamente slides de etapas (`DIA 01`, `DIA 02`...), horários (`08:30`), distâncias (`km`), alertas `ZBE` e slides de `FICHA TÉCNICA`.
* **Cruzamento Automático com `.kmz` / `.kml`:** Associa as coordenadas GPS exatas de cada marcador (*Placemark*) do Google My Maps às respetivas paragens extraídas do PowerPoint.
* **Exportação & Partilha `.json`:** Permite exportar a viagem compilada e enviá-la aos restantes membros do grupo de mota para importação num clique.
